# Simple Notes App

A small full-stack Notes application built to practice the MERN stack.

## Tech Stack

- React
- Node.js
- Express
- MongoDB
- Mongoose

## Current Progress

- Project setup completed

- Express server created

- Backend running on port 5000
- Note schema and model created
- POST /notes API created
- Tested POST API using PowerShell and Postman

- GET /notes API created
- Tested GET API using Postman
- Successfully fetched notes from MongoDB Atlas
- DELETE /notes/:id API created
- Tested DELETE API using Postman

## API Endpoints

| Method | Endpoint   | Purpose       |
|   ---  |  ---       |  ---          |
| POST   | /notes     | Create a note |
| GET    | /notes     | Get all notes |
| DELETE | /notes/:id | Delete a note |
